# 微信图片导出

用户确认 HTML 后再按请求导出，内部测试图片放工作目录。

工具需要 Node.js 与 Playwright（或 playwright-core），支持已安装浏览器。优先使用环境中已有依赖，不擅自下载安装浏览器。

```sh
node scripts/export-wechat.cjs <当前HTML文件> <图片输出目录> <文件名前缀>
```

可通过 `QUOTE_PLAYWRIGHT_MODULE` 指定已安装 Playwright 包的目录，通过 `QUOTE_BROWSER_EXECUTABLE` 指定浏览器程序路径。未指定时使用标准包与其默认 Chromium。具体路径运行时发现，不写入技能包。

输出包括完整长图、编号分图、图片 ZIP 及 manifest.json。清单记录输入文件的 SHA-256、图片尺寸与切分位置，确保分图来自同一 HTML。不要将清单作为商家必读文件。

可用 `--width`、`--scale`、`--target-height` 调整尺寸；打包需要 Python 3，可用 QUOTE_PYTHON_EXECUTABLE 指定。只接受内嵌图片，阻断网络资源；相对路径图片须先内嵌。

默认1080像素宽，优先控制每张约2800像素高；在 h2、独立 h3、示例卡和证据块的起点切分，跳过表格、图片和卡片内部边界。完整块过高时保留整块并报告，不硬切图片；必要时修改 HTML 排版后重新导出。

导出后至少查看报价页、模板页和较长诊断页，核对总价、图片比例与切分点。脚本成功不等于视觉审阅完成。遇到超长块或拥挤布局先调整再交付。

失败条件：输入不存在或非 HTML、依赖不可用、图片加载失败、页面横向溢出。失败时不宣称图片已交付。工具不删除旧图片，最终回答只链接清单中本次输出的文件，避免残留旧页被误发。
