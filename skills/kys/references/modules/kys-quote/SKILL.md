# 商家报价 HTML 与图片

## 共用规则

制作前读取 工具箱根目录的 `references/quote-common.md`。餐饮小红书采集与诊断归 kys-diagnosis；本模块处理已确认方案的排版，用户明确指定本模块时可用于餐饮。

## 任务

接收已经确认的方案结论、价格和素材，交付一个可独立打开的 `.html` 文件，按请求附加可直接发给客户的分段纵向 PNG 图片。采用 `assets/quote-reference.html` 的视觉结构和实际导图流程作为基准；它是样例，不是其他商家的事实来源。

## 必须保持

1. **内容先定，排版后做。** 从对话或用户文件提取已确认的商家名称、目标、数量、单价、总价、执行边界和配图。缺少会改变报价的项目时先指出缺口，不自行补价。
2. **所有数字复核。** 每行金额等于数量乘单价；套餐价格单列；分类合计与总价一致；正文、表格、交付汇总、图片中的数字一致。发现先前结论算错时明确修正。
3. **以通用报价方案为版式基准。** 保留纵向阅读、醒目的核心数字、清楚的章节、预算表、内容示例和最终交付。按新商家的业务增删章节，不强行套用样例的策略或预算。
4. **配图对应内容。** 有用户提供的真实截图或照片时，选最能说明该板块的图片，标注“形式参考”“商家实拍”等实际身份。不得把别人的笔记说成该商家的成果。没有素材时用明确标注的排版示意，不伪造案例。
5. **按请求交付。** 默认 HTML；请求微信图片时导出完整长图、分图和 ZIP；用户只要一种格式时只交该格式。HTML 中图片应嵌入为 data URI，确保单文件下载后仍能打开。
6. **客户可读。** 采用商家能理解的标题和说明；内部分工、成本推断和未确认承诺不进入客户版。价格、范围、交付和阶段边界优先展示。

## 工作流程

1. 读取当前对话与用户材料，先列出内部核对表：方案范围、项目、数量、单价、金额、总计、素材、尚未确认项。不要把内部核对表直接写进客户文件。
2. 读取 `references/layout-and-content.md` 和 `assets/quote-reference.html`。复用 CSS、页面节奏与分图方式；全面替换品牌、业务事实、金额、图片与案例说明。保持最终 HTML 无外部图片或字体依赖。
3. 写入客户可直接查看的 HTML。预算、执行逻辑、交付汇总各自可读，避免同一数字在不同处写法相冲突。对实际交付无法保证的流量、销售和排名不用保证式表述。
4. 仅在用户请求图片时运行 `python3 scripts/export_images.py <html绝对路径> --output <图片目录绝对路径>`。脚本按章节边界导出编号 PNG，并生成 `manifest.json`。根据当前页面高度可调整 `--target-height`，使每张图片便于微信查看。
5. 检查每张图片的首尾、文字清晰度、图片加载和章节切点。若出现截断、大片空白、错字或过小的模板截图，修改 HTML 或分图高度后重新导出。
6. 按请求交付 HTML；需要图片时交付顺序编号 PNG、完整长图和 ZIP。向用户简述采用了哪些配图、是否为示例，列出尚未确认的商业事实。

## 素材和缺口

- 有完整价格结论：直接制作。
- 缺少商家素材但文字和预算完整：用示意版制作，明确标注待替换的图片位置。
- 缺少数量或单价且无法从已确认套餐推出：继续制作不依赖该项的结构和版式，再只问会改变报价的最少问题。未确认价格不得写入客户版。
- 用户只要单纯报价表：保留核心预算与交付，可缩短策略章节，按用户请求输出 HTML 或图片。
- 用户要求从零设计打法、试探预算或比较营销方案：转入方案讨论；本 Skill 只在结论明确后负责成品化。

## 完成检查

- 总价和各项金额复核通过；所有输出数字一致。
- HTML 本地打开可显示，图片无丢失；请求图片时，图片按序完整覆盖全页。
- 截图中的文字在手机查看时清晰，章节没有被切成难读的两半。
- 参考案例与商家真实内容被清楚区分。
- 已交付真实文件路径，不把设计说明当成文件。

## 附带资源

- `assets/quote-reference.html`：不含客户资料的通用参考版式；仅用于视觉参考。
- `references/layout-and-content.md`：可变内容映射与客户版边界。
- `scripts/export_images.py`：将 HTML 稳定导出为按章节切分的 PNG。

## 依赖与安装

本子 Skill 随 kys 工具箱维护，可通过名称独立调用，但安装时必须保留 kys 的完整目录，不能单独复制本目录。共享规则和脚本以本文件向上三级的工具箱根目录解析，始终使用同一份资源。

## 历史报价查询

需要历史客户报价或单项价格参考时调用 `$kys-pricing`，带上客户、月份、配置和平台条件；仅作历史参照，不自动套为当前报价。遇到金额或数量冲突先标明，不将账面金额当作已收款。
