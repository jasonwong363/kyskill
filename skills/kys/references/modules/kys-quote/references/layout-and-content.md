# 通用报价参考版式与替换规则

参考文件：`../assets/quote-reference.html`。

## 可复用的是版式

- 红棕色封面、大标题、副标题与三项关键数据；
- 米白底色、编号章节、卡片、预算表与最终交付汇总；
- 纵向单页，最大宽度约 760 CSS 像素；
- 内容示例与对应说明并排，手机窄屏自动改为紧凑布局；
- 图片嵌入 HTML，点击参考图可放大；
- 按章节边界切成适合微信连续阅读的编号图片。

## 必须替换的是事实

| 位置 | 新商家要核对的内容 |
| --- | --- |
| 封面与关键数字 | 商家名、项目名、阶段、预算、交付总量 |
| 背景与策略 | 当前业务、目标客群、渠道、已确认打法及不做事项 |
| 预算表 | 执行项目、数量、单价／套餐价、金额、总计 |
| 内容方向 | 与商家产品和服务有关的搜索词、主题和形式 |
| 内容示例 | 新商家或用户授权提供的截图、照片与实际标签 |
| 执行与交付 | 顺序、阶段目标、验收口径、交付数量 |

任何参考方案中的金额、数量、地区、品类和第三方素材均不能自动沿用。用户明确要求复用某一项时才采用，并重新核对。

## 内容示例的选择

对每张候选图判断：它展示哪种内容形态、与哪个执行板块对应、是否会让客户误以为它是自己的既有成果、缩小到手机宽度后能否看出重点。优先选 2 至 4 张，具体对应方案板块。截图保留必要的上下文，图片旁用一句话说明“参考什么”。

## 出图前核对

预算表、正文和交付卡片的数量要完全一致。图片高度优先控制在 1,500 至 2,200 CSS 像素，章节较长时可以略超；不要切断一张参考图或一个价格表。导图后逐张目视检查。
